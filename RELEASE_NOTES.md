# Release 1.1.0

August 13, 2026.

This release establishes `distance-antimagic-research` as the canonical publication-facing repository for the project.

It covers three research threads: universal/all-labeling classifications, nonlinear finite-field Cayley constructions, and the exhaustive order-nine theorem. The large order-nine certificate archive remains in the dedicated repository `zach7036/distance-antimagic-order9` and is linked from the main README.

The release also records the corrected scope: the general Kamatchi-Arumugam conjecture is not solved, and the fixed noncyclic-group pair problem remains open in full generality for groups of exponent greater than two.
