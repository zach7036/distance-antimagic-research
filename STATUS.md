# Research status

**Updated:** August 13, 2026

## Evidence status by research track

### Universal-labeling results

The repository describes a cyclic/all-abelian universal classification, an exact signed-sum support theorem, Johnson set-system rigidity, structural graph classifications, complementary-neighborhood obstructions, phantom periods, and an elementary-abelian-2 switching classification.

**Public evidence currently in this repository:** summaries only. The full manuscript and proof details are not yet committed. These statements should be treated as unrefereed theorem candidates, not independently verified theorems.

### Nonlinear finite-field results

The repository describes a translation-sum/Hasse framework, affine-line filters, nonlinear constructions in dimension three and higher dimensions, explicit finite-field examples, and a dimension-two obstruction for the full-line architecture.

**Public evidence currently in this repository:** summaries only. The full manuscript, explicit certificates, and verification code are not yet committed. These statements should be treated as unrefereed theorem candidates.

### Exhaustive result through order nine

The companion repository contains a manuscript, C++ certificate constructor, two independent verifiers, catalogue provenance, expected hashes, result tables, sample certificates, and a deterministic reproduction script covering all 274,668 unlabeled graphs of order nine and all 205,914 eligible classes.

**Public evidence:** <https://github.com/zach7036/distance-antimagic-order9>

**Status:** a credible finite computer-assisted result with public reproducibility materials; not peer reviewed.

## Explicitly unresolved

- The Kamatchi-Arumugam conjecture is not solved in general.
- The fixed noncyclic-group pair problem is not fully classified for groups of exponent greater than two.
- The even-degree Cayley problem on elementary abelian 2-groups is not fully classified.
- No proof-assistant formalization is available.
- Priority remains provisional pending specialist review and database-level literature searches.
